    Frequently Asked Questions
    Why is a game not loading?
    Make sure your service worker is active. Try refreshing the page or clearing site data in your browser settings, then reload Nova.
    How do I report another user?
    Open the Social tab, find the user in a chat, and use the ⋯ menu next to their message to report them.
    Why can't I access certain sites?
    Some sites block proxy traffic. Try a different URL or search for an alternative version of the site.
    How do I suggest a game?
    Use the "Vote for Apps & Games" card in either library to suggest an addition and vote on what Nova should add next.
